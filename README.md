# CampusMarket

A student marketplace concept for buying and selling phones, clothes, books, electronics and campus essentials.

## Current version
This is a responsive front-end prototype with:
- Product browsing, search and categories
- Demo seller listings
- Create-account/sign-in interface
- Demo sell-product form
- Demo chat interface

## Important
GitHub Pages can host the website interface, but **real multi-user accounts, secure authentication, product storage, image uploads and realtime chat require a backend/database**. A production version can use a service such as Supabase or Firebase connected to this front end.

## GitHub Pages
Upload all four files to a public repository and enable Pages from the `main` branch and `/ (root)`.
